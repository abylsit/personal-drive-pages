Privacy policy

Effective October 15, 2026.

This policy describes abylsit's personal Google Drive connection, configured using rclone, and this informational website.

Data accessed and purpose

With the owner's authorization, rclone accesses Google Drive file names, folder structure, metadata, and file contents to display and operate a mounted Drive folder. It reads, creates, updates, or deletes files when requested by the owner.

Storage and retention

OAuth credentials are stored in rclone's configuration on the owner's computer. Opened files and pending uploads may be cached locally. The configuration uses a 24-hour cache age target and a 5 GB cache size target; files in use or awaiting upload may be retained longer. Credentials remain until removed or revoked.

Sharing and use

This configuration communicates with Google to carry out Drive operations. It does not send Drive data to this website, sell personal data, use it for advertising, or use it to train AI models. It has no separate application server.

Owner controls and deletion

The owner can stop the mount service, revoke the application's access in Google Account settings, and remove local rclone credentials and cached files. Ensure pending uploads finish before deleting cache files. Removing local credentials or cache does not by itself delete files stored in Google Drive.

Website hosting

This static website uses no analytics scripts, forms, or application cookies. GitHub Pages hosts it and may process visitor connection information under GitHub's privacy statement.

Contact

Contact the maintainer through the project issue tracker. Do not post private data or credentials.
