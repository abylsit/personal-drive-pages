PERSONAL GOOGLE DRIVE CONNECTION

Personal Drive

Personal Drive is abylsit's private desktop configuration of the open-source rclone tool. It connects the owner's Google Drive to a folder on the owner's Linux computer.

What it does

After the owner authorizes access through Google, rclone can list, download, upload, rename, and delete Drive files as requested through the mounted folder. The requested Google Drive permission enables these file operations.

Runs on the owner's computer

This website explains the configuration. It does not offer a login, collect Drive files, or run the Drive connection. Authorization credentials and cached files are stored locally by rclone.

Read the privacy policy and terms of use. Questions about this configuration can be raised through the project issue tracker; never include credentials or private files.
